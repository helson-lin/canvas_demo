# Review 清单（reviewer 在每个分支合并前执行）

## 通用
- [ ] 只改了自己拥有的文件；共享文件无改动（或已在 handoff 提出变更请求）
- [ ] `pnpm typecheck && pnpm test && pnpm build` 通过（reviewer 本地复跑）
- [ ] 无新增未声明依赖；无 `any` 逃逸；无 console 残留
- [ ] handoff 完整，已验证项可复现

## 数据正确性（重点）
- [ ] 保存的位置是世界坐标；屏幕坐标只出现在事件处理
- [ ] 删除节点后无悬空边；删除进行中占位节点不产生资产
- [ ] 生成结果新建 Asset，不修改原图片节点
- [ ] 图片节点状态由任务派生，节点不存 status
- [ ] 状态转换立即 saveNow；Blob 先于文档引用落盘
- [ ] 刷新后不存在永久 queued/running

## 交互
- [ ] 鼠标锚定缩放：锚点不漂移（0.1 / 1 / 4 倍）
- [ ] 节点内输入控件不触发拖动/删除
- [ ] 运行中重复点击生成有提示且不重复提交
