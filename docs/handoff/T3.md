## 做了什么
- `graph.ts`：补全 `canConnect`（节点不存在 / 自环 / 生成节点作输入 / 非生成节点目标 / result 边仅 generator→image / 重复边，均带中文 reason）；`edgesOf`、`inputEdgesOf`（+ 规格名别名 `inputsOf`）、`findDanglingEdges`；纯几何 `hasHandle`、`handlePoint`、`bezierPath`、`bezierMidpoint`、`edgeEndpoints`。
- `Handle.tsx`：自包含 `<Handle node side />`，相对 NodeFrame 绝对定位（左/右边缘、`size.h/2`），与 `handlePoint` 一致；输出把手 pointerdown 开始连线并 `stopPropagation`；拖线悬停在生成节点时输入把手高亮（合法主色 / 非法红色）。
- `useConnect.ts`：模块级预览 store（`useSyncExternalStore`，不进入 doc）；window 级 pointermove/up、Esc 取消；pointerup 用 `document.elementFromPoint` + `closest('[data-node-id]')` 找目标；非法 → `toast('无法连接', { description: reason })`；合法 → `addEdge` + `persistence.saveNow()`。空白处或回到源节点松开 = 静默取消。
- `EdgeLayer.tsx`：world 容器内 SVG（overflow visible），三次贝塞尔；input 实线、result 虚线；`vector-effect: non-scaling-stroke`；14px 透明命中路径；点击 `select({ edgeIds: [id] })`，选中高亮；hover/选中时中点显示 × 按钮（屏幕像素恒定大小），点击 `removeEdges` + `saveNow()`；同时渲染连线预览虚线。只依赖 store 数据，节点移动自动跟随。

### 容器偏移的取法
优先 `handle.closest('[data-canvas-root]')` 的 `getBoundingClientRect()`；若不存在，则由把手自身推导：`offset = 把手中心 client 坐标 − worldToScreen(handlePoint(source,'out'), viewport)`。因此**无需** T1 加属性也能工作；加上后更直接（见契约请求中的建议）。

## 集成说明（T1 / T2）
1. **Handle**（T2 在各节点组件中，或 T1 在 NodeFrame 内统一）：
   ```tsx
   <NodeFrame node={node} selected={selected} title="…"
     handles={<><Handle node={node} side="in" /><Handle node={node} side="out" /></>}>
   ```
   两个都放即可，`Handle` 按类型自动隐藏。要求：NodeFrame 根元素保持 `position: absolute`、`data-node-id`、left/top = 世界坐标、宽 = `size.w`（当前 T0 已满足）。把手纵向锚定在 `size.h/2`，节点若因内容长高超过 `size.h`，把手与边仍在 `size.h/2`（两者一致）。
2. **EdgeLayer**：保持 Canvas.tsx 现状——作为 world 变换容器的第一个子元素（在节点之前）。
3. T1 的拖动/平移应忽略 `data-no-drag` 目标（Handle 和边都带此属性，并已 stopPropagation pointerdown）。
4. **Delete 键删除选中边** 由 T1 的键盘处理负责：对 `ui.selection.edgeIds` 调 `removeEdges` + `persistence.saveNow()`。
