## 做了什么
- `src/services/mockTaskService.ts`：`createMockTaskService({ now? })` 实现 `TaskService`。内存 Map + `idempotencyKey` 去重；`setTimeout` 驱动 queued(queueMs)→running(runMs)→终态；按 `params.aspectRatio` 返回 `MOCK_OUTPUTS` URL。失败在提交时确定性决定：`#fail`→`CONTENT_REJECTED`；`failAll`/`failNext`（消费后 `setMockConfig({ failNext: false })`）→`MOCK_FORCED_FAILURE`；空输入 submit 直接 reject（`code: EMPTY_INPUT`）。`resume()` 由 queuedAt/startedAt/now 计算剩余时长，超过 `expected + 10s`（`RESUME_GRACE_MS`）返回 `resumable:false`；resume 不再消费 failNext。
- `src/services/taskRunner.ts`：
  - `startGeneration`：活动任务 → toast「任务进行中」；空输入 → toast（含 EMPTY_INPUT），不建任务；一次 `transact` 建 Task(queued, queuedAt, expectedDurationMs=queueMs+runMs, idempotencyKey, resultNodeId) + 占位 ImageNode（generator 右侧 +40px，世界坐标）+ `result` 边 + `activeTaskId`；`await saveNow()` 后 `service.submit`。
  - 轮询 500ms，状态变化 `patchTask` + `saveNow`。成功：先 `await persistRemote(url, taskId)`，再一次 `transact` 写占位 assetId、清 pendingTaskId、task succeeded + resultAssetId。占位被删/任务被取消 → 丢弃结果（若 persistRemote 已登记 origin 为该任务的资产，同一 transact 中删除，避免孤儿文档资产）。
  - `retryTask`：新 Task（attempt+1、retryOf、新 idempotencyKey、同 snapshot/params/resultNodeId），占位 pendingTaskId 与 generator.activeTaskId 指向新任务，旧任务保留。
  - `cancelTask`、`resumeTasks`（不可恢复 → `interrupted` / `INTERRUPTED` / 页面刷新导致任务中断）、超时守卫（从 queuedAt 起 `expectedDurationMs × 3` → failed `TIMEOUT`）。
- 测试：`src/services/__tests__/mockTaskService.test.ts`（5）、`taskRunner.test.ts`（9），全部 fake timers。

## 契约变更请求（共享文件需改动时填写，勿直接改）
| 文件 | 改动 | 理由 |
| --- | --- | --- |
| `src/domain/types.ts` 或 `taskApi.ts` | 在 `Task` 上加 `remoteTaskId?: string`，或 `SubmitTaskRequest` 加可选 `taskId` | 目前本地 Task id 与服务返回的 taskId 不同，runner 用内存 Map 关联；刷新后通过 `resume({ taskId: 本地 id })` 让 Mock 以本地 id 重新挂载。真实后端需要持久化远端 id 才能恢复。 |
| `src/services/assetStore.ts`（T5） | 明确 `persistRemote` 负责登记 Asset(generated, origin.taskId) 并返回 assetId | runner 假设如此（与该文件注释一致）；runner 不自己写 Asset，因为 blobKey 由 T5 决定。 |

## 已知问题 / 限制
- 端到端成功依赖 T5 `persistRemote`；刷新恢复依赖 T5 在 hydrate 后调用 `resumeTasks()`。
- 丢弃结果时 T5 已写入的 Blob 不会被删除（runner 不知道 blobKey）；文档中的孤儿 Asset 会被移除。
- `resume` 重新切分 queue/run 使用当前 mockConfig.queueMs（请求里只有总时长）。
- 旧任务的远端 Mock 计时器在 `removeNodes` 取消时由下一次轮询调用 `service.cancel` 清理。
