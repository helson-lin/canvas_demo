# Handoff — C1 Toolbar

- 分支 / 最后提交：`feat/c1-toolbar` / 本 handoff 所在提交
- 状态：功能完成；见下方协作约束冲突

## 做了什么

- 用 beUI Dock、Tooltip 和 lucide 图标实现顶部工具栏，提供图片、提示词、生成节点及载入示例入口。
- 新节点以当前屏幕中心换算出的世界坐标居中放置，连续创建时沿两个轴各偏移 24 屏幕像素，视口改变后重置偏移；创建后选中并立即保存。
- 载入示例时创建一个 URL 资产、三个 `sample: true` 节点和两条输入边，选中生成节点，不提交生成任务；完成后显示中文 toast 并立即保存。
- 新增组件测试，覆盖三类节点、缩放视口坐标、连续偏移、视口重置及示例图。

## 已知问题 / 限制

- `src/ui/Toolbar.tsx` 原桩标记 `OWNER: T2`，但 `docs/specs/C1-toolbar.md` 指定 C1 拥有该文件；本提交依照 C1 文件清单将标记改为 C1。
- AGENTS.md 要求跨实体写操作放在 services 中，而 C1 规格只允许修改 Toolbar、其测试和 handoff，并要求在工具栏中调用 `upsertAsset`、`addNode`、`addEdge`。当前示例创建按规格调用现有 store actions；若 reviewer 要求原子化，需要将该流程迁至 services 并扩展 C1 可修改文件清单。
- 协作期间共享工作目录的当前分支被并行集成了 T2/T4/T5 提交；本 C1 提交本身仅包含 Toolbar、其测试和本 handoff。工作目录另有其他任务的未提交文件，未纳入本提交。
