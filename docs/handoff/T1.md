## 做了什么
- `src/canvas/usePanZoom.ts`：原生监听器（wheel 为 `{ passive: false }`）。
  - ctrl/meta+wheel 与触控板 pinch → `zoomAt(vp, 鼠标相对容器坐标, exp(-deltaY*0.01))`，范围 0.1–4。
  - 普通 wheel → 平移。
  - 空白处左键、中键（任意位置）、Space+左键（任意位置）拖动平移；pointer capture；光标 grab/grabbing；阻止中键自动滚动。
  - 空白处点击（<3px）清空选择。
  - Delete/Backspace（焦点不在 input/textarea/select/contenteditable）→ `removeEdges` + `removeNodes`，随后 `persistence.saveNow()`（AGENTS §3.6：节点增删走 saveNow）。
  - 视口变化后 `persistence.scheduleSave()`。
- `src/canvas/useNodeDrag.ts`（新建）：`pos = start + (now - startScreen)/zoom`；setPointerCapture；rAF 合并 `moveNode`；<3px 视为点击（选中，Shift 切换加选）；拖动选中组中的节点时整组移动；拖动结束 `scheduleSave()`。命中 `[data-no-drag], input, textarea, button, select` 不开始拖动。纯函数 `dragPosition` / `exceedsDragThreshold` / `nextSelection` 已导出并有单测。
- `src/nodes/NodeFrame.tsx`：挂载拖动处理器，`touch-none`，标题栏 `cursor-move`，选中 `ring-2`（选中态由节点组件传入 `selected`）。
- `src/canvas/Canvas.tsx`：容器加 `touch-none overscroll-none`（world 容器 translate+scale、origin 0 0 保持 T0 实现）。
- `src/canvas/__tests__/coords.test.ts`：往返、zoomAt 锚点不变（3 视口 × 3 点 × 5 倍率）、clamp 边界、wheel 因子对称、拖动数学、点击选择。

## 已知问题 / 限制
- 未浏览器手测；store 快照未提供。
- 节点内部控件（input 等）上的 pointerdown 不会平移画布（因为在节点内）；这是有意的。
- 连线（T3）的 Handle 需要标 `data-no-drag` 或自行 `stopPropagation`，否则从 Handle 拖出会触发节点拖动。
- 边的选中（点击边）由 T3 负责调用 `select({ edgeIds })`；T1 只负责 Delete 删除。
- 点击节点时会把 edge 选择清空。
