## 做了什么
- `ImageNode`：按 `selectImageNodeView` 渲染 ready（`useAssetUrl` 图片）/ queued·running（beUI Loader + AnimatedBadge）/ failed（任务错误信息 + 重试 → `retryTask`）/ missing（“图片缺失” + 示例图选择 + 本地上传 → `importFile`，失败 toast）。
- `PromptNode`：textarea（`data-no-drag`）→ `updateNodeData` + `persistence.scheduleSave()`，显示字数。
- `GeneratorNode`：通过 `selectGeneratorInputs` 列出引用图片缩略图与提示词（2 行截断）；比例用 beUI Tabs segment（写 params + scheduleSave）；StatefulButton 生成按钮，状态派生自 `selectActiveTask`（queued/running→loading 且禁用，succeeded→success，failed/interrupted→error）；活动任务时按钮上覆盖透明层，点击 toast“任务进行中”（禁用按钮不派发 click）；显示最近任务 Badge、失败原因、重试。
- 节点头部：lucide 类型图标 + 中文标题 + 「示例」标签（短 ID 由 NodeFrame 渲染）。
- 新建 `src/ui/NodeStatus.tsx`：`NodeStatus`（TaskStatus→AnimatedBadge 中文标签）、`NodeTitle`。
- store 订阅收窄：GeneratorNode 把输入序列化成字符串做 selector，避免无关文档变化触发重渲染；ImageNode 只订阅 view 字符串与自身 pending task。
