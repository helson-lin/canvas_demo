# Handoff — T0 Foundation

- 分支：`feat/t0-foundation`
- 状态：完成

## 做了什么
- Vite 8 + React 19 + TS strict + Tailwind v4 + shadcn（radix-nova 主题）脚手架，别名 `@/`。
- beUI 组件（`src/components/motion/`）：button-base、button-stateful、input、tabs、switch、animated-badge、loader、animated-toast-stack、tooltip、dock、drawer、context-menu。
  - 注：beUI 的正确安装方式是 `npx shadcn@latest add @beui/<name>`（`https://beui.dev/r/<slug>.json` 返回 404）。
  - 删除了 shadcn init 生成的 `src/components/ui/button.tsx` 及其引入的第三方 `cn` 包，统一用 `@/lib/utils` 的 `cn`。
- `src/domain/`（纯 TS）：types、ids、graph（canConnect/edgesOf/inputEdgesOf/findDanglingEdges）、selectors、migrations 框架、taskApi（TaskService 契约 + DTO + 错误码）、samples。
- `src/store/canvasStore.ts`：全部 actions 已实现，含级联删除、删除时取消进行中任务、`transact` 原子更新。
- `src/canvas/coords.ts`：screenToWorld / worldToScreen / zoomAt / clampZoom。
- `src/persistence/api.ts`：PersistenceAdapter 契约；`src/ui/toast.ts` + `Toaster.tsx`（beUI toast stack）。
- T1–T5 桩文件（带 `// OWNER: Tn`），App 布局与启动流程（initPersistence → hydrated）。
- `public/samples/`：3 张示例图 + 3 张 mock 输出图（SVG）。
- `AGENTS.md`（协作约束）+ `CLAUDE.md`（引用 AGENTS.md）；ARCHITECTURE 与各规格路径已改为 `src/domain`。

## 对外暴露的接口
见 `src/domain/index.ts`、`src/store/canvasStore.ts`（`CanvasState`）、`src/domain/taskApi.ts`（`TaskService`）、`src/persistence/api.ts`（`PersistenceAdapter`）、`src/ui/toast.ts`（`toast()`）。

## 与原规格的差异
- 目录由 `src/model` 改为 `src/domain`；selectors、migrations、TaskService 契约并入 domain。
- 新增 `Task.retryOf`、`Node.sample` 字段；`Edge.kind` 改为必填。
- `persistRemote(url, originTaskId)` 多一个参数用于写 `Asset.origin`。
