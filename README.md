# AI 创作无限画布（MVP）

单项目 AI 图片创作画布：在画布上放置图片、提示词、生成节点，连线后运行一次**异步 mock 生成**，结果成为新的图片节点；刷新页面后画布、结果和任务状态全部恢复。纯前端实现，无后端、无真实模型。

## 运行

```bash
pnpm install
pnpm dev          # http://localhost:5173
```

其他命令：`pnpm test`（Vitest，110 个用例）、`pnpm typecheck`、`pnpm lint`、`pnpm build`。需要 Node 20+ 与 pnpm 10。

## 功能与操作

| 功能 | 操作 |
| --- | --- |
| 新建节点 | 顶部工具栏：图片 / 提示词 / 生成；新节点出现在视口中心附近的空位 |
| 空画布 | 中央显示开始引导与「载入示例」；有节点后底部常驻一行操作提示（平移 / 缩放 / 连线 / 删除） |
| 示例数据 | 工具栏或空画布引导的「载入示例」：1 图 + 1 提示词 + 1 生成节点（带「示例」标记，不会自动生成） |
| 平移 | 空白处左键拖动、中键拖动、Space + 左键拖动、触控板双指滑动 |
| 缩放 | Ctrl/⌘ + 滚轮或触控板捏合，**以鼠标位置为中心**；右下角 − / + / 100% / 适配全部 |
| 拖动节点 | 拖动节点标题或空白区域；Shift 点击多选，拖动多选时整体移动 |
| 连线 | 从图片/提示词节点右侧圆点拖到生成节点上松开；非法连接会提示原因 |
| 删除 | 选中节点或连线后按 Delete/Backspace；悬停连线点击 ×。删除节点前会弹出确认（说明将一并删除的连线数与将被取消的进行中任务数，默认焦点在「取消」，Esc 取消）；只删连线不需确认 |
| 图片节点 | 选择示例图，或上传本地图片（刷新后可恢复） |
| 生成 | 生成节点显示当前引用的图片与提示词，选择比例后点「生成」。结果节点使用 beUI ImageGeneration，图片占满卡片、下方一行状态与提示词：排队中 → 生成中 → 细化中 → 已完成。同一生成节点的结果在其右侧按 3 列网格排布；提交时若结果在视口外会自动平移显示，完成提示可点「定位」；双击结果查看大图 |
| 触发失败 | ① 提示词包含 `#fail`；② 右上角「Mock 控制台」打开「下一次任务失败」或「所有任务失败」 |
| 取消 | 任务排队或生成中，生成节点显示「取消任务」；取消后结果节点显示「已取消」，可重试 |
| 重试 | 失败 / 中断 / 取消后点「重试」，沿用原输入快照与参数，复用同一个结果节点 |
| 保存 | 自动保存到 IndexedDB，左下角显示保存状态 |

> 演示重试成功请用「下一次任务失败」开关（只生效一次）。`#fail` 触发的失败在重试时会再次失败，因为重试使用提交时的输入快照。

## 架构与关键取舍

详细设计见 [ARCHITECTURE.md](ARCHITECTURE.md)，协作约束见 [AGENTS.md](AGENTS.md)。

**数据模型**（`src/domain/types.ts`）：`CanvasDocument { version, viewport, nodes, edges, assets, tasks }`，四类实体都有稳定 ID（`node_ / edge_ / asset_ / task_` 前缀）。

- **坐标**：节点只保存**世界坐标**。`screen = world × zoom + offset`；滚轮缩放用 `zoomAt` 保持鼠标下的世界点不动；拖动位移 = 屏幕位移 ÷ zoom。画布只有一个 `translate + scale` 容器，节点与连线都在其中，因此平移缩放后相对位置天然稳定。
- **连接与资产引用**：图片节点只引用 `assetId`；生成结果永远**新建 Asset + 新图片节点**，不会覆盖原图。连线分 `input`（图片/提示词 → 生成）与 `result`（生成 → 结果，仅用于溯源）。删除节点在同一个 store 动作中级联删除连线并取消其进行中的任务。
- **异步任务**：`TaskService` 接口（`submit / get / cancel / resume`）与未来后端同构；`MockTaskService` 用定时器推进状态，页面每 500ms 轮询。失败完全确定（`#fail`、开关），不依赖随机数。生成节点有进行中任务时拒绝重复提交并提示。
- **生成中刷新**：提交时就在一次原子更新中创建「任务 + 结果占位节点 + result 连线」并**立即保存**；图片节点的显示状态由任务派生（节点不存状态字段）。成功时先把图片 Blob 写入 IndexedDB，再更新文档引用。刷新后：仍在预期时长内的任务按剩余时间**继续执行**；超时的转为「已中断」可重试；另有 3 倍预期时长的超时守卫，**不会永久停留在生成中**。
- **持久化**：IndexedDB（idb-keyval）。状态转换、增删节点立即保存；拖动/视口/文本 300ms 防抖；写入串行化，旧快照不会覆盖新快照；`pagehide` / 页面隐藏时补存。文档带 `version`，加载时逐级迁移（附 v0→v1 示例迁移），高于当前版本则只读启动、不覆盖存储。
- **自研画布而非 React Flow**：交互是评分重点，自研后坐标换算、事件顺序都可完整解释。
- **单包 + `src/domain` 纯层**：需求为单项目、后端不在范围内，未采用 monorepo；`src/domain` 禁止依赖 React/DOM/存储（有单测守卫），对接后端时可原样抽成共享包。

### 后端化方案（追问准备）

- **接口**：`POST /tasks`（Header `Idempotency-Key`，body：generatorNodeId、inputs(assetIds, prompts)、params）→ `202 { taskId }`；`GET /tasks/:id`；`POST /tasks/:id/cancel`；重试 = 新任务并关联 `retryOf`。
- **超时但服务端可能已接收**：`idempotencyKey` 在提交前生成并已持久化，超时后用同一个 key 重发，服务端按 `(user, key)` 唯一索引返回已有任务；前端拿到的服务端 ID 保存在 `Task.remoteTaskId`，刷新后优先按它、其次按 key 对账（mock 已实现同样逻辑）。
- **资源与节点**：图片上传走对象存储（预签名 URL），`assets` 表存元数据；画布文档只存 `assetId`。删除节点不删资产，资产按引用计数或定期 GC 回收（前端对应 `gcBlobs`）；文档保存带 `revision` 做乐观锁。

## 已验证场景

浏览器手测（Chromium 内核浏览器，本地 dev server）：

1. 空画布显示开始引导与操作提示 → 工具栏新建三类节点；载入示例，节点不重叠且高度随内容自适应。
2. 缩放 2 倍时拖动节点，节点跟手（位移 = 屏幕位移 ÷ zoom）；Ctrl+滚轮缩放后锚点世界坐标不变（误差 < 1e-12）。
3. 从把手拖线连接到新的生成节点，生成节点即时显示引用的图片与提示词；点击连线 + Delete、悬停 × 删除连线；删除节点需确认（Esc 取消后节点与连线保留，确认后节点及其 3 条连线一并删除）。
4. 生成：排队中 → 生成中 → 细化中 → 已完成；结果在视口外时自动平移显示，完成 toast「定位」可选中结果；连续生成 7 次结果按 3 列网格排布；双击结果打开大图；原图片节点不变。
5. `#fail` 提示词失败并显示原因；「下一次任务失败」→ 失败 → 重试成功（第 2 次，复用同一占位节点）；生成中「取消任务」→ 结果显示「已取消」→ 重试成功。
6. **生成中刷新**：刷新后任务继续并成功，结果图从 IndexedDB Blob 恢复。
7. **长时间关闭后打开**（将存储中的任务 queuedAt 改为 60 秒前模拟）：显示「已中断：页面刷新导致任务中断」，重试成功。
8. 刷新后节点、位置、连线、视口（78%）、结果与任务终态全部恢复；IndexedDB 中文档 `version: 1`、生成资产为 blob 引用。
9. **本地上传**（以 DataTransfer 模拟选择文件）：320×200 PNG 写入 IndexedDB Blob，刷新后在同一节点恢复。

自动化测试覆盖：坐标换算与锚点缩放、拖动数学、连接校验、级联删除、任务状态机（fake timers：成功、防重、失败重试、`#fail`、空输入、删除占位节点、刷新恢复与超期中断、超时守卫、幂等去重、按 key 恢复）、持久化（往返、迁移、未来版本拒绝、并发保存、Blob 恢复、悬空连线修复）、组件（节点各状态、工具栏、Mock 控制台、状态栏、删除确认、空画布引导）、删除确认流程、结果网格排布与视口定位，以及 `src` 无静态循环依赖。

## 已知限制

- 结果图片是按比例选择的固定示例图（需求允许），但每次都是独立的任务与资产记录。
- 节点宽度固定、高度随内容自适应（渲染后测量并写回 `node.size`，连线锚点随之更新）；暂不支持手动调整尺寸、框选、撤销重做、小地图。
- 上传在浏览器中以脚本模拟文件选择验证，未手动操作系统文件对话框。
- 多标签页同时编辑同一画布时后写覆盖先写（无跨标签同步 / 冲突检测）；接后端后用文档 `revision` 乐观锁解决。
- 节点在放置后变高（如出现错误行）可能与下方节点贴近，不会自动推开。
- 资产（Asset 记录）为追溯保留、不随节点删除；启动空闲时 `gcBlobs` 仅回收无 Asset 引用的孤儿 Blob。
- 构建产物约 520 kB（motion + radix），未做拆包。
- 开发模式下热更新替换 store 模块后画布可能停在「加载画布…」，整页刷新即可（生产构建无此问题）。

**下一步会先改**：把任务轮询改为可插拔的 `TaskService` HTTP 实现（接口已就位），并为画布拖动加入 E2E（Playwright）回归测试，防止事件顺序类问题回归（开发中已出现并修复过一次：连线点击被画布空白点击逻辑取消选中）。

## 依赖、现成代码与 AI 使用

- 主要依赖：React 19、Vite 8、TypeScript、Tailwind CSS v4、Zustand + immer（状态）、idb-keyval（IndexedDB）、nanoid（ID）、Vitest + Testing Library + fake-indexeddb（测试）。
- 现成代码：UI 控件来自 [beUI](https://beui.dev)（通过 `npx shadcn add @beui/<name>` 拷贝到 `src/components/motion/` 与 `src/components/agents/`，未修改；ImageGeneration 自带的英文重试按钮未使用，改为自有「重试」按钮），图标为 lucide-react。画布、连线、任务引擎、持久化均为本项目实现。
- AI 工具：使用 Claude Code（主会话负责架构、拆解、review 与集成；子代理并行实现 T1–T5）与 Codex（实现 C1 工具栏）。过程与关键取舍见 [docs/AI_LOG.md](docs/AI_LOG.md)，各模块交付记录见 [docs/handoff/](docs/handoff/)。
